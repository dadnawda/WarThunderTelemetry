# 怎么打开 & 怎么用

## 一、打开程序（二选一）

### 方式 A：双击脚本（推荐）

打开文件夹 `C:\Users\1\Desktop\wt\WarThunderTelemetry\`，双击 **`run.cmd`**。

脚本会自动启动程序，并在启动失败时把错误直接打出来。

```
C:\Users\1\Desktop\wt\WarThunderTelemetry\src\WarThunderTelemetry.App\bin\x64\Debug\net10.0-windows10.0.26100.0\win-x64\WarThunderTelemetry.exe
```

> 双击后如果没反应，去同目录看有没有 `crash.log` —— 有就是启动时报了异常，把内容发我。

## 二、界面说明

启动后出现主窗口「**战雷遥测仪表台**」，左侧三个页面：

| 页面 | 作用 |
| --- | --- |
| **仪表盘** | 常看的飞行数据，大字号卡片显示 |
| **全字段** | 游戏接口返回的**所有**原始字段，带搜索和来源筛选 |
| **设置** | 选显示哪些字段、调字号/透明度、开关联网抓载具参数 |

顶部常驻状态条显示：**连接状态** · **当前载具** · **告警信息**。右上角有「**显示悬浮窗**」按钮。

## 三、两个悬浮区域

程序有**两块互相独立的悬浮区**，可以同时开、分别摆位置：

| | **遥测悬浮窗** | **武器发射参数悬浮区** |
| --- | --- | --- |
| 显示什么 | 你勾选的飞行数据（速度/高度/G/油量…） | 当前挂载导弹的**最佳发射参数**与**发射建议** |
| 默认位置 | 屏幕左侧竖排（左上） | 屏幕右下 |
| 默认外观 | **纯文字，无背景无边框** | **纯文字，无背景无边框** |
| 默认字段 | 39 项（**全部可选字段**） | 固定几行核心结论 |
| 开关 | 设置页「显示悬浮窗」/ 状态条按钮 | 设置页「**显示武器参数悬浮区**」 |

两块悬浮区**互不影响**：位置、字号、颜色、锁定状态各自独立。

### 3.1 怎么开关

- **遥测悬浮窗**：主窗口右上角「显示 / 关闭悬浮窗」按钮，或设置页的开关。
- **武器悬浮区**：设置页 →「武器发射参数悬浮区」→ 打开「**显示武器参数悬浮区**」。

### 3.2 怎么拖动 / 拉伸 / 锁定

两块悬浮区**操作方式完全一样**：

1. **拖动** —— 未锁定时，**整块面板随便按哪里都能拖**（不光是顶部一条窄带，按在文字上也能拖）。
2. **拉伸** —— 未锁定时，把鼠标移到**边缘或角落**，光标会变成拉伸箭头，按住拖即可。默认**不显示**拉伸提示角标，想要提示可以在设置页打开「显示拉伸提示」。
3. **锁定 + 鼠标穿透** —— **双击面板**即可锁定：锁定后鼠标点击会**直接穿透到游戏里**，不挡操作，同时拖不动也拉不动。
4. **解锁** —— 回设置页关掉「锁定悬浮窗」（或对应武器区的锁定开关）。

### 3.3 为什么看着"没有窗口"

默认状态下悬浮区**没有背景板、没有边框、没有标题栏**，看上去就是**一行行文字直接浮在游戏画面上**。

这是刻意的默认值 —— 悬浮窗最怕挡视线，纯文字最干净。

> **文字描边**：为了让文字在天空、地面、云层上都看得清，程序会自动给每个字加一圈**极细的深色（浅色主题则为浅色）描边**。这个描边是跟着字号自动算的，不需要你设置。

如果你确实想要一块半透明底垫着（比如画面上内容太杂），去设置页打开「**显示背景面板**」，再把「背景不透明度」拉到 0.3~0.5 就行。

### 3.4 外观设置（设置页「悬浮窗外观」区）

两块悬浮区各有**独立**的一份外观设置（武器区在「武器发射参数悬浮区」区里）。

| 设置项 | 说明 |
| --- | --- |
| **显示背景面板** | **默认关闭** = 只有文字，全透明，无边框 |
| **背景不透明度** | 0~1，只在开了背景面板时生效；拖到 0 也等于全透明 |
| **背景颜色** | 取色器，深色画面上选黑、浅色画面上选白 |
| **名称文字 / 数值文字** | 分开设色，数值可以更醒目 |
| **字号** | 12~36，改完悬浮区会**自动重新适配尺寸** |
| **紧凑行距** | 同样高度能多显示几行 |
| **显示拉伸提示** | 默认关；开了才在右下角显示拉伸角标 |
| **一键配色** | 深色主题 / 浅色主题 / 荧光绿，三套调好的组合 |

### 3.5 字段能显示多少

**没有数量上限**。设置页「悬浮窗字段」列表里，游戏接口能提供的数据项**全部可选**，默认全勾（当前共 **39 项**）。

- 勾多少，悬浮窗就显示多少行，高度不够时会**自动出现滚动条**，不会漏字段。
- 「**全选 / 全不选**」按钮一键操作。
- 悬浮窗行布局是**「名称 + 数值」两列右对齐**，名称长了会自动换行，不截断。
- 「跟随仪表盘设置」按钮 = 悬浮窗直接用仪表盘那份字段清单。

> 悬浮窗字段和仪表盘字段**互不影响**，各自记各自的。

> 想恢复位置？设置页点「**重置悬浮窗位置与尺寸**」—— 悬浮区被拖到屏幕外找不回来时用这个。武器区也有同样的「重置」。

## 三·补、武器发射参数悬浮区

这块专门解决一件事：**「我现在这发导弹，能不能打、多远打、什么时候打最合适」**。

### 3.6 它显示什么

打开后是一小块纯文字，从上到下大致是：

| 行 | 内容 |
| --- | --- |
| 导弹名 / 剩余弹量 | 当前挂载的导弹型号，以及还能打几发 |
| **发射建议** | 一句话结论，并带颜色：**绿=可发射**、黄=勉强能打、橙=太远/太近、红=禁止发射 |
| **不可逃逸区 (NEZ)** | 目标在这个距离内基本躲不掉 |
| **有效射程** | 综合当前高度/速度/态势后的**实际**可用射程 |
| **最小发射距离** | 比这更近打出去来不及解算/引信解锁 |
| **预计命中时间** | 导弹飞到目标大约几秒 |
| 本机状态 | 空速 / 高度 / 当前过载（可关） |

### 3.7 为什么它会随情况变

这一块是**本地实时算的**，不是查表查死的。同一发导弹，在下面这些情况下**算出来的射程会不一样**：

- **你飞得越高** → 空气稀薄、阻力小 → 射程更远
- **你飞得越快** → 给导弹的初速加成更大 → 射程更远
- **迎头对飞**（对方朝你飞）→ 闭合率高 → 射程更远
- **尾追**（对方背对你飞）→ 闭合率低 → 射程明显缩水
- **你当前过载太大** → 如果超过这发导弹的**发射过载限制**，会直接判**禁止发射**（很多早期红外弹拉到 6~7G 就打不出去了）

所以这块面板的价值就在于：**它是"此刻"的答案，不是说明书上的理论值**。

### 3.8 目标信息要手填（重要）

游戏自己的 8111 接口**不提供敌机数据**（没有目标距离、没有目标速度、也没有相对态势）。所以：

- **本机状态**（速度/高度/过载）是**自动读**的，实时刷新。
- **目标距离 / 目标速度 / 目标高度 / 态势（迎头/尾追/侧向）**需要你在设置页**手动输入**。

不填也能用 —— 这时程序会给一个**保守的射程区间**，并在面板上标注出来，绝不会编一个假的目标距离糊弄你。

> 设置页「武器发射参数悬浮区」里有四个输入框：**目标距离(m) / 目标速度(km/h) / 目标高度(m) / 态势**，填完即时生效，点「**清除目标信息**」恢复成保守模式。

### 3.9 导弹型号怎么识别

**默认自动识别** —— 程序读游戏接口里的武器名字段，去内置导弹库里匹配。

如果没认出来（不同版本接口字段名可能变），有两个办法：

1. 设置页「武器发射参数悬浮区」里有一个**导弹型号下拉框**，手动选一发，程序会一直用你选的这个。
2. 下拉框里每选一发，下面会显示这发导弹的**参数摘要**（制导方式、最大过载、最大射程等），方便你核对是不是选对了。

> 程序还有一层保底：**如果某次刷新时接口临时丢了这个字段，会沿用上一次识别到的型号**，不会突然变成"未识别"。

### 3.10 导弹数据是哪来的

内置参数库收录了 **30 种**战雷常见导弹（AIM-9 系列、AIM-7、AIM-54、R-3/R-13/R-60/R-73、R-23/R-24/R-27/R-40、R-77、R550、PL-2/PL-5、Skyflash、Aspide、AGM-65、AGM-114、9M114、9M120、Kh-29 等）。

数据全部来自**战雷公开资料**：

- 官方 **wiki** 的导弹条目表格（锁定距离 / 发射距离 / 最大速度马赫 / 最大过载 G）
- 官方**论坛**的导弹性能整理帖（燃烧时间 / 飞行时间 / 发射过载限制 / 导引头参数）

**数据纪律**：查得到的就填真实值；**查不到的一律留空，走保守估算**，并且这发导弹的结论上会标注「**含估算值**」——宁可说"我不确定"，也不编一个数字给你。

### 3.11 计算是什么原理

不是查表，是**本地跑一个简化的弹道模型**：

1. **动力段 + 惯性段两段式推力** —— 按导弹的燃烧时间算加速，烧完就靠惯性飞。
2. **简化大气阻力** —— 按高度给一个空气密度系数（高空阻力小），再按速度给一个阻力系数。
3. **交战态势闭合率** —— 迎头 ×1.45 / 尾追 ×0.65 / 侧向 ×1.00。
4. **本机速度加成** —— 以 900 km/h 为基准，每快 100 km/h 射程加约 4%，封顶 ±40%。
5. **过载门限** —— 本机当前 G 超过导弹发射限值就直接判禁止发射。

整个过程**纯本地、瞬时完成**，不联网、不抓网页，所以**游戏里不会卡顿，断网也能用**。

## 四、开始用之前

**必须让游戏跑起来**，程序才能读到数据：
1. 启动《战争雷霆》
2. 进入一局（机场/空中才算，机库不行）
3. 界面顶部状态条变绿 → 显示「已连接」

没连上会显示「未连接（等待游戏启动）」，这是正常的。

> 游戏需用「**无边框窗口**」或「**窗口化**」模式。独占全屏下任何非注入叠加层都无法显示。

## 五、关于载具告警阈值

程序会读你当前开的机型，自动套用对应的告警阈值（超速、G 限、失速等）。

- **首次**遇到某架飞机时，会联网去 wiki 抓一次参数并缓存，抓取期间先用兵种通用阈值兜底。
- 抓不到也没关系，会退回兵种缺省阈值，功能不会中断。
- 设置页可看到「已缓存 N 架载具」，也有手动刷新/清空按钮。
- 不想联网？设置页关掉「联网获取载具参数」，之后只走本地缓存。

## 八、出问题怎么办

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 双击没反应 | 启动异常 | 看 EXE 同目录的 `crash.log` |
| 弹框说需要 Windows App Runtime | 系统运行时缺失 | 本工程已改自包含，正常不该出现；若出现说明 build 配置被改动 |
| 一直显示「未连接」 | 游戏没开或没进对局 | 确认游戏已进局 |
| 悬浮区看不到 | 被主窗口挡住 / 位置在屏幕外 | 设置页点「重置悬浮窗位置与尺寸」（武器区有独立的重置按钮） |
| 悬浮区拖不动/拉不动 | 处于锁定状态 | 设置页关掉对应区域的「锁定」 |
| 悬浮区挡住了游戏操作 | 忘了锁定 | **双击面板**即可锁定并开启鼠标穿透 |
| 设置了背景还是不透明 | 背景不透明度没拉到位 | 「背景不透明度」拉到 0，或直接关掉「显示背景面板」 |
| 武器区显示「未识别」 | 接口字段名对不上 | 在设置页下拉框里**手动指定**导弹型号 |
| 武器区射程看着不对 | 目标信息没填 | 填上目标距离/速度/态势；不填只给保守区间 |
| 武器区标注「含估算值」 | 这发导弹有参数查不到 | 正常，程序用保守估算兜底，不编数值 |
| 设置页改动没生效 | — | 所有改动都是即时生效的；若悬浮区已锁定，外观改动仍会生效，位置类不会 |

## 战雷遥测悬浮辅助 v1.1.0

### 本次更新：导弹库换为实测数据 + 新增飞行模型推演

**导弹参数库全面更换。** 原先是 30 枚、靠公开资料整理的粗略值；
现在换成社区数据挖掘表《WT导弹与设备性能表 2.44.0.23》的**游戏实测数值**，
收录 **76 枚空空导弹**（红外 41 / 雷达 35）。

新增收录的先进空空弹包括：

- 中系：霹雳 12 / SD-10A、PL-12A、**PL-15**、霹雳 8 / Pyton-3、PL-9、天燕 90
- 美系：**AIM-120A/B、C5/C7、D** 全系、AIM-54A、AIM-7C/D/E/E-2/F、AIM-4G
- 俄系：R-77 / RVV-AE、R-77-1、R-27ER/ET、R-27R/T、R-24R/T、R-73(E)
- 其他：Mica-EM、DERBY、AAM-4、R-Darter、Pyton 4、TC-1L（天剑一）

**发射包线改为物理推演。** 不再是「标称射程 × 修正系数」，而是逐帧积分
导弹的速度-距离曲线（推力 / 质量衰减 / 二次阻力 / 密度随高度衰减），
再用数据表实测的「最大飞行距离」反推阻力系数做锚定 ——
曲线形状来自物理，绝对量来自数据，两头都不编。

**收录纪律**：核心飞行参数（推力/燃烧/极速/最大距离/滞空/增速/阻力系数）
至少占 3 项才收录；源表空列（如 AIM-7M、PL-2）**直接剔除而不是猜一个数**。
缺失字段仍走保守估算并在界面标注「含估算值」。

### 系统要求

- 64 位 Windows 10 版本 1809 (17763) 或更高 / Windows 11
- 无需安装 .NET 或其他运行库，所需组件全部内置

### 安装后注意

1. **游戏必须用「窗口化」或「无边框窗口」模式**，独占全屏下任何叠加层都无法显示（Windows 显示机制决定，非本程序问题）
2. 首次运行若弹出蓝色的「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」（程序未购买代码签名证书，属正常现象）
3. Windows 11 的「智能应用控制」(Smart App Control) 可能拦截未签名程序，处理方法见压缩包内 `使用说明.txt` 第四节

### 功能

- **遥测悬浮窗**：高度 / 速度 / 垂直速度 / 过载 / 马赫数 / 油量 / 转速等 39 项字段，可自由勾选
- **武器发射参数悬浮区**：给出最小射程 / 不可逃逸区 / 有效射程 / 最大射程、命中时间与末段速度，并按当前本机状态给出「可发射 / 太远 / 太近」判断；本机过载超限时标红
- 两个悬浮窗各自独立：位置、字号、配色、锁定状态分开配置
- 整块可拖动，四边四角可拉伸（边缘有高亮提示），双击锁定后鼠标穿透到游戏

### 数据说明

- 游戏 8111 接口**不提供雷达目标数据**，目标距离 / 速度 / 态势需在设置页手动填写，填了才有精确的发射判断，不填则只显示射程区间
- 查不到的导弹参数一律走保守估算并在界面标注「含估算值」，不编造数值

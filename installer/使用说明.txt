========================================
 战雷遥测悬浮辅助  WarThunderTelemetry
========================================

一、这是什么
------------
读取《战争雷霆》游戏本机 8111 端口提供的飞行遥测数据，
用一个始终置顶、背景透明的悬浮窗，把关键飞行参数和导弹发射
参数直接叠在游戏画面上。

全程只读取游戏自己开放在 127.0.0.1:8111 的数据，
不修改游戏文件，不注入游戏进程，不联网上传任何东西。

本程序完全绿色：不写注册表、不装服务、不需要安装。
删掉整个文件夹就等于卸载。


二、怎么运行
------------
1. 把整个文件夹解压到任意位置（建议英文路径，别太深）。
2. 双击 WarThunderTelemetry.exe

注意：必须把【整个文件夹】一起拷过去。
     这是自包含版本，文件夹里的 dll 是运行必需的一部分，
     单独把 exe 拿出来无法启动。


三、系统要求
------------
- 64 位 Windows 10 版本 1809 (17763) 或更高 / Windows 11
- 本包已内置 .NET 10 运行时与 Windows App SDK，
  目标电脑无需安装任何东西。


四、第一次打开可能遇到的问题
----------------------------
【1】弹出蓝色的「Windows 已保护你的电脑」
     原因：exe 没有购买代码签名证书，Windows SmartScreen
           对陌生程序默认拦截，属正常现象。
     处理：点「更多信息」→「仍要运行」。

【2】双击后没有任何反应
     先看同目录下有没有生成 crash.log：
       - 有 crash.log：把这个文件内容发给我。
       - 没有 crash.log：多半被杀毒软件静默拦掉了，
         请把本文件夹加入杀软白名单后重试。

【3】提示被「智能应用控制」(Smart App Control) 阻止
     这是 Windows 11 的一项安全策略，会拒绝加载未经签名、
     没有云端信誉记录的程序。本程序的 dll 未做代码签名，
     可能被它拦下。
     处理（二选一）：
       a) 用管理员 PowerShell 执行下面这行后重启电脑：
          Set-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Control\CI\Policy' -Name 'VerifiedAndReputablePolicyState' -Value 0
       b) 或从「Windows 安全中心 → 应用和浏览器控制 →
          智能应用控制」里关掉它。
     注意：智能应用控制关闭后需要重装系统才能重新开启。


五、游戏里的必要设置
--------------------
游戏必须用【窗口化】或【无边框窗口】模式运行。

独占全屏（Exclusive Fullscreen）下，任何不注入游戏的叠加层
都无法显示在画面上 —— 这是 Windows 的显示机制决定的，
不是本程序的问题。

在游戏里切换：设置 → 图像 → 显示模式 → 选「窗口」或「无边框」。


六、基本用法
------------
1. 打开程序后，点主界面的「显示悬浮窗」。
2. 游戏里就会叠上数据。两个区域各自独立：
   - 遥测悬浮窗：飞行参数（默认左上）
   - 武器参数悬浮区：导弹发射参数（默认右下）
3. 调整位置：解锁状态下按住悬浮窗任意位置拖动。
4. 调整大小：拖四周边缘（鼠标移到边上那条线会亮起来）。
5. 锁定 / 解锁：双击悬浮窗（锁定后鼠标穿透到游戏）。
   锁定后仍然可以双击边缘一圈来解锁。
6. 全部选项都在主界面的「设置」页里：
   显示哪些字段、字号、颜色、背景透明度、导弹型号、目标距离等。
   武器悬浮区的配色默认跟随主悬浮窗，改一次即可。


七、关于武器发射参数
--------------------
导弹发射包线是本机离线计算的（内置 76 种空空导弹实测参数（含 PL-12/PL-15、AIM-120 全系、R-77、R-27ER 等）），不联网。

游戏的 8111 接口【不提供】雷达锁定的目标数据，所以目标距离、
速度、态势需要在设置页手动填写。填了才会给出精确的
「可发射 / 太远 / 太近」判断；不填则只显示该导弹在当前高度、
速度下的射程区间。

查不到的导弹参数一律走保守估算，界面上会标注「含估算值」，
不会编造数值。


八、目录里都有什么
------------------
WarThunderTelemetry.exe       主程序，双击运行
WarThunderTelemetry.dll       程序主体
WarThunderTelemetry.Core.dll  遥测解析与武器计算
WarThunderTelemetry.pri       界面资源索引（删了会打不开）
*.xbf                         编译后的界面文件（删了会打不开）
*.dll                         运行库（.NET 10 + Windows App SDK），别删
使用说明.txt                  本文件
crash.log                     仅在出错时生成，可删

有问题把 crash.log 发给我就行。
